# 观相 · 面相文化网

一个关于中国传统「面相」文化的静态网站，包含三大板块：

1. **面相基础知识**（`basics.html`）—— 三停、五官、十二宫及天庭/印堂/人中/地阁等部位名称与具体阐述，并附「天庭饱满地阁方圆」「印堂发黑」等常见面相言论的理性分析。
2. **面相经典案例**（`cases.html`）—— 范蠡识勾践、曾国藩《冰鉴》、汉高祖「隆准龙颜」、项羽「重瞳子」、袁天罡相武后、孔子「听其言而观其行」等识人故事。
3. **智能面相分析**（`analyze.html`）—— 上传正脸照片，AI 识别人脸 68 个关键点，测量三停比例与五官形态，自动生成个性化面相解读报告。

## 目录结构

```
mianxiang/
├── index.html          # 首页
├── basics.html         # 面相基础知识
├── cases.html          # 经典案例
├── analyze.html        # 智能面相分析
├── css/
│   └── style.css       # 全局样式
└── js/
    └── analyze.js      # 人脸识别与面相分析逻辑
```

## 使用方式

- **直接打开**：双击 `index.html` 即可在浏览器中浏览（无需构建、无需服务器）。
- **智能面相分析**依赖联网加载人脸识别库与模型（CDN），首次分析需联网并等待模型下载数秒。

## 技术说明

- 纯静态 HTML / CSS / 原生 JavaScript，无构建步骤。
- 人脸检测与关键点定位使用 [@vladmandic/face-api](https://github.com/vladmandic/face-api)（face-api.js 的维护分支），通过 jsDelivr CDN 加载。
- 分析逻辑：检测人脸 68 关键点 → 计算三停比例、脸型、眉/眼/鼻/口/下巴/人中/颧骨等几何特征 → 结合传统相学知识生成报告。
